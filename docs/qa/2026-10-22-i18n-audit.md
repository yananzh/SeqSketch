# 中英文界面检查记录

检查日期：2026-10-22。检查与修复已完成，最终完整测试为 **798 passed**，进程退出码为 **0**。

## 检查范围

- 45 个功能页的英文与简体中文可见文案、下拉选项、提示、表头和嵌套页签。
- 45 个功能帮助窗口的中文标题与正文，以及帮助中引用的选项名称。
- Windows 下默认 920 × 700 窗口；中文界面另以 150% Qt 缩放渲染复查。
- FASTA 工具预览摘要、操作日志、SSR 结果类型、常用图表的标题/坐标轴/图例及关于窗口。
- 中文选项下的互补转换、序列翻译、双序列比对、去重、排序、正则筛选、SSR 预设/筛选/导出。

## 发现与修复

| 问题 | 修复 |
| --- | --- |
| 大量下拉选项仍显示英文 | 静态选项加入翻译，独立保留英文源值与现有 `userData`，计算和命令参数继续使用源值 |
| SSR 的六组阈值在中文下重叠、超出窗口 | 改为两行、每行三组的网格布局 |
| qPCR 的最小/最佳/最大标签被固定宽度截断 | 改为独立列标题，三行参数使用简短标签 |
| 按钮宽度在翻译前计算 | 按中文文本重新测量，并保留原有按钮宽度档位 |
| 长固定宽度标签可能被截断 | 中文文本过长时允许换行 |
| 关于窗口底部链接被固定高度裁切 | 增大默认尺寸与最小尺寸，允许调整窗口大小；补齐构建说明翻译 |
| FASTA 预览摘要、图表文字存在遗漏 | 新增选项、预览和图表语言包，共 224 条翻译 |
| Sequence Logo 的 Information 与消息框 Information 含义不同 | 显示模式使用“信息量”，消息框继续使用“提示”；英文显示和内部值保持原样 |
| 帮助正文中的选项名称与中文界面不一致 | 同步中文帮助中的相关名称 |
| 新选项回调可能延长 Qt 控件生命周期 | 使用弱引用并添加回归测试，最终全套测试正常退出 |

用户提供的序列 ID、书签内容、文件路径、表格列名及外群名称不作翻译。工具名称、学名、格式标识和命令行参数保留其原始写法。SSR 的中文结果类型在 CSV 中仍导出英文源值。
