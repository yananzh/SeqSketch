**SeqSketch 1.0.1 — 2026-10-02**

本版本修复[代码质量评估](code-quality-review-2026-10-02.md)中的 15 项问题。

科学计算有两项需要重新分析旧结果的变化：标准密码表的 ENC 按全部同义家族的类别权重估计；缺少必要类别的有效观察、每个可用家族不足两个密码子，或使用非标准密码表时，显示和导出 N/A，不再给出虚假的低 ENC。计算仍使用有限样本校正，上限为 61；短序列的估计可能不稳定。标准代码的参考公式为 `2 + 9/F2 + 1/F3 + 5/F4 + 3/F6`，每个 F 是对应类别可估计家族的平均同义纯合度。算法依据 [Wright, 1990](https://pubmed.ncbi.nlm.nih.gov/2110097/)；非标准密码表暂未实现经过独立核验的扩展。

JC69/K80 距离遇到无可比核苷酸位点的序列对会明确报错，并说明样本名称。U 按 T 处理。旧版把这种缺失数据当作零距离，相关树应重新生成。

Sanger 组装支持完整 IUPAC 反向互补；只有相等的 A/C/G/T 才计入可信的重叠匹配。每个输入只允许一条 FASTA 记录，避免拼接多个独立 reads。非法字符会提示错误。

运行中关闭标签页或窗口会请求取消并等待线程实际结束，界面保持响应。关闭中的任务不再弹出完成/错误对话框。外部工具取消会终止进程树；POSIX 启动器创建独立会话，只终止本应用拥有的进程组。

MAFFT/MUSCLE 在转换为字典之前检查主要序列 ID 的唯一性，描述不同的相同 ID 也会被拒绝。比对输出检查样本身份及等长、非空序列。MAFFT 保存失败后恢复操作按钮并保留已计算的比对，可再次保存。

One Step 的 Excel 样本 ID 限定为字母、数字和下划线；错误提示包含 Excel 行号。基因显示名映射为安全、唯一的文件及分区 ID，映射写入 `run_manifest.json`。路径分隔符、路径跳转和指向输出目录外的符号链接会被拒绝。Windows 保留名称、大小写及后缀冲突均有处理。

One Step 恢复运行使用 manifest 中的真实 artifact 路径及 SHA-256 校验。输入相同且中间文件有效时，建树恢复只执行 IQ-TREE；文件缺失、修改或旧 manifest 缺少校验信息时，从头重新运行。恢复后的报告保留分区顺序和缺失样本说明。MAFFT 以临时文件读取输入，解决 Windows 中文输出目录的路径问题。

NCBI 下载允许无版本 accession 匹配实际返回版本；显式版本保持严格匹配。下载报告保留请求到返回 accession 的对照，支持旧式 pipe header。下载和 MAFFT 保存使用运行开始时的路径快照；运行时禁用修改相关控件及 Clear。原子保存失败不会截断已有结果文件。相对输出路径也会在实际父目录记录 `run_log.txt`。

Windows 子进程输出显式解码，默认中文编码环境下的测试不再因解码错误失败。Windows 打包优先使用 System32 的系统 DLL，避免其他 PATH 程序的 ICU 被错误收集而导致 QtCore 无法加载。启动日志使用可写的用户数据目录，保留便携版的数据位置约定。新增开发验证命令：

```powershell
py main.py --smoke-test
py -m scripts.validate_tool_chain --output-dir dist/quality-validation/tool-chain
```

`--smoke-test` 打开十个核心标签页、检查教学资源并正常退出；自动化执行可设置 `QT_QPA_PLATFORM=offscreen`。真实工具链命令离线使用八物种 cytb 示例，执行一次完整流水线，再验证恢复时只运行 IQ-TREE。

Windows 验证及依赖版本见[交付验证记录](release-validation-1.0.1.md)。macOS 原生运行与打包尚未在本次 Windows 环境验证。
