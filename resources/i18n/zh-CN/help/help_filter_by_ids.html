按 ID 筛选 — 按 ID 选择或移除序列

本工具有什么用？
你提供一组 FASTA 记录 ID，工具会根据所选的匹配模式，仅保留这些记录或将其移除。

快速入门

  1. 选择一个 FASTA 文件
  2. 输入或粘贴你的 ID 列表（每行一个）
  3. 选择匹配模式和输出顺序
  4. 点击预览，检查前几条匹配结果
  5. 选择结果的保存位置，然后点击运行

应使用哪种匹配模式？

你的目标→ 选择此模式
提取 ID 与列表完全一致的序列（例如 NM_001101.5） → Exact Match (case-sensitive)
同上，但忽略大小写差异（例如 geneA 可匹配 genea） → Exact Match (case-insensitive)
保留 ID 包含某个关键词的序列（例如 kinase 可匹配 NM_kinase_1） → Contains (case-insensitive)
同上，但区分大小写 → Contains (case-sensitive)
移除部分序列，保留其余全部 → Remove Listed IDs (exclude)

什么是“输出顺序”？它为什么重要？

  • Preserve FASTA Order — 序列保持输入文件中的原始顺序。对大多数流程而言是安全的选择。
  • Preserve Query Order — 输出序列与你粘贴的 ID 列表顺序一致。适用于下游工具需要特定顺序的情况（例如固定的基因组合）。

如何输入 ID

  • 直接输入到文本框中，每行一个
  • 可同时写出缺失 ID 报告，与输出文件一并保存，便于查看 FASTA 文件中哪些 ID 没有匹配结果

实用示例

  • 提取一组基因：粘贴一组登录号（NM_001101.5），选择Exact Match (case-sensitive)，并勾选导出缺失 ID 报告
  • 移除污染序列：列出不需要的 ID，并切换到Remove Listed IDs (exclude)
  • 重新排序序列：按所需顺序粘贴 ID，并选择Preserve Query Order

使用技巧

  • 对大文件运行前，请先使用预览，确认 ID 匹配正确
  • 如果没有提取到任何序列，请检查 ID 是否与 FASTA 序列头完全一致，并尝试不区分大小写的模式（case-insensitive）
