正则筛选 — 用模式匹配 FASTA 记录

本工具有什么用？
工具会用正则表达式模式扫描你的 FASTA 文件（默认匹配序列头），并保留（或移除）匹配的记录。你可以控制模式在哪里查找（ID、描述或两者），以及匹配时是否区分大小写。

快速入门

  1. 选择一个 FASTA 文件
  2. 输入正则表达式（或点击示例载入现成的表达式）
  3. 选择匹配模式、匹配范围和大小写设置
  4. 点击预览，在保存前检查匹配结果
  5. 选择输出文件，然后点击运行

匹配范围 — 模式在哪里查找？

例如，对于如下 FASTA 序列头：

>NM_001101.5 Homo sapiens protein kinase

重要：标记 FASTA 序列头的开头字符 > 不属于任何匹配范围。工具在去掉 > 后读取该行，因此只包含 > 的模式永远不会匹配任何内容。请改用匹配 ID 或描述文本的模式（例如 ^NM_、kinase）。

范围扫描内容"^NM_" 的匹配示例
Full HeaderID + 描述（不含 >）NM_001101.5 Homo sapiens protein kinase
Sequence ID Only第一个空格之前的文本（不含 >）NM_001101.5
Description Only第一个空格之后的文本（不匹配）
Sequence序列本身的字母ATG...（若序列以匹配 NM 的字母开头；适用于基序筛选）

正则表达式速查

^字符串开头$字符串结尾
.*任意字符.+任意一个或多个字符
\d数字 [0-9]\w单词字符
[A-Z]大写字母[a-z]小写字母
+一个或多个*零个或多个
|或（选择）(...)捕获组

实例

  • 提取 RefSeq 条目：模式 ^N[MP]_|^X[MP]_，范围 Sequence ID Only，匹配模式 Include Matches
  • 查找所有激酶：模式 kinase，范围 Full Header，匹配模式 Include Matches
  • 去除污染序列：模式 contaminant|vector，匹配模式 Exclude Matches
  • 按物种筛选：模式 Homo sapiens，范围 Description Only

使用技巧

  • 运行前务必先预览——正则表达式很容易写错。
  • 请勿在模式中包含 >——它是 FASTA 序列头标记，不属于可搜索的文本。
  • 序列头中大小写混杂时，请使用忽略大小写。
  • 启用导出未匹配报告，保留筛选设置和匹配数量的记录。
  • 若模式没有产生任何输出，请尝试放宽条件（先去掉 ^ 或 $ 锚定符）。
