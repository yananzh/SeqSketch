比对修剪（trimAl） — 清理你的多序列比对

本工具有什么用？
trimAl 会从多序列比对（MSA）中移除比对质量差或空位过多的列。 更干净的比对能产生更准确的系统发育树，并让下游分析更可靠。

快速入门

  1. 通过添加文件按钮或拖放添加比对文件。
  2. 选择输出文件夹（会根据第一个文件自动填入）。
  3. 选择修剪方法（建议从 automated1 开始）。
  4. 点击运行。

修剪方法

  • gappyout — 移除空位比例异常高的列。较为保守 — 保留的数据最多。
  • automated1 — 根据比对统计量自动选择最佳方法。推荐的默认选项。
  • strict — 依据比对统计量进行更激进的修剪。
  • strictplus — 与 strict 类似，但还会过滤掉较短的序列片段。
  • nogaps — 移除所有含空位的列。最严格的选项 — 输出中不含缺失残基 （当下游分析要求完整列时很有用）。

输出格式

  • FASTA — 默认格式，兼容大多数工具。
  • PHYLIP — 用于 IQ-TREE / RAxML。
  • NEXUS — 用于 MrBayes / BEAST。
  • CLUSTAL — ClustalW 格式。
  • MEGA — MEGA 格式。

使用技巧

  • 对大多数数据集，从 automated1（默认值）开始；gappyout 是更保守的选择；nogaps 是最严格的选项。
  • 修剪完成后，可将输出用于最大似然树构建（IQ-TREE）或MSA 可视化。
  • 每次运行后查看日志，了解列数的变化以及是否有警告。
  • 支持的输入格式：FASTA、CLUSTAL、PHYLIP、NEXUS（会自动转换）。
