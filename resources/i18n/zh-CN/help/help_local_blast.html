本地 BLAST — 用本地数据库检索查询序列

本工具有什么用？
使用 NCBI BLAST+ 工具包，在本地 BLAST 数据库中检索你的查询序列。结果会按你选择的格式保存到输出文件，可用任意电子表格软件或文本编辑器打开。

快速入门 — 使用现有数据库

  1. 设置 BLAST+ 路径（若已内置则自动检测）。
  2. 选择你的查询 FASTA文件。
  3. 选择数据库：将数据库文件（*.phr / *.nhr）拖放到该字段，或点击管理从已保存的数据库中选择 — 数据库名称字段会显示匹配的已保存记录。
  4. 选择 输出格式（默认：TSV，12 列），并设置输出文件路径。
  5. 点击运行。

快速入门 — 创建新数据库

  1. 在创建新数据库区域，选择输入 FASTA和输出文件夹，并输入数据库名称。
  2. 点击构建数据库 — 新数据库会构建完成，并自动选中到上方的数据库文件和数据库名称字段中。
  3. 选择查询 FASTA文件并点击运行。

BLAST 程序

blastn→ DNA → DNA
blastp→ 蛋白质 → 蛋白质
blastx→ DNA（翻译）→ 蛋白质
tblastn→ 蛋白质 → DNA（翻译）
tblastx→ DNA（翻译）→ DNA（翻译）

程序会根据查询序列和数据库类型自动选择，你也可以手动覆盖。

参数

E-value→ 随机命中的最大期望数量。数值越低越严格。常用：1e-5（一般）、1e-10（严格）。
线程数→ 用于并行检索的 CPU 核心数。默认：2。
最大命中数→ 每条查询序列最多报告的目标序列数。默认：50。
输出格式→ 输出格式。6 (TSV) 输出 12 个制表符分隔的列；0（双序列比对） 为人类可读的比对结果；5 (XML) 供程序化使用。建议的输出文件名会随所选格式更新。

输出列（outfmt 6）

1qseqid→ 查询序列 ID
2sseqid→ 目标（数据库）序列 ID
3pident→ 相同匹配的百分比
4length→ 比对长度
5mismatch→ 错配数
6gapopen→ 空位开放数
7–8qstart / qend→ 查询序列的比对范围
9–10sstart / send→ 目标序列的比对范围
11evalue→ 期望值
12bitscore→ 位得分

使用技巧

  • 所有文件输入字段都支持拖放 — 无需点击“浏览”按钮。
  • 使用管理可选择、置顶、重命名、移除或定位已保存的数据库。置顶的数据库会始终排在已保存列表顶部。
  • 数据库列表会自动去重 — 同一个数据库不会出现两次。
  • 对于较大的查询文件，可增加线程数以加快检索。
  • 点击示例可使用内置数据体验预配置好的 E. coli 蛋白质 BLAST。
  • 清空只重置查询输入 — 正在填写的创建新数据库表单会保持原样。
  • BLAST 运行或数据库构建完成后，结果文件夹会打开包含输出文件 / 新数据库的文件夹。
