书签 — 管理已保存的序列

本工具有什么用？
通过拖放、实时搜索、JSON 导入以及 JSON/HTML 导出，把常用 URL 分类整理。所有书签都会自动保存到你的用户数据文件夹中。

快速入门

  1. 点击添加分类创建文件夹，或右键点击左侧面板。
  2. 点击添加书签或按 Ctrl+D 添加新书签。
  3. 双击书签即可在浏览器中打开。
  4. 在搜索框中输入内容，按名称或 URL 筛选。

键盘快捷键

  • Ctrl+D — 添加书签
  • F2 — 重命名所选书签
  • Delete — 删除所选书签

导入 / 导出

  • 导入 — 从 JSON 文件合并书签。
  • 导出 JSON — 备份或分享你的书签。
  • 导出 HTML — Netscape 格式，兼容 Chrome/Firefox/Edge。

使用技巧

  • 在分类之间拖动书签，即可快速重新整理。
  • 右键点击面板可打开包含更多选项的上下文菜单。
  • URL 重复时会弹出确认提示。
