系统树可视化（Toytree） — 高级树渲染

本工具有什么用？
使用 toytree + toyplot 渲染并导出系统发育树，提供丰富的样式选项。 支持多种布局、中点 / 外群定根、支持值显示，以及可直接用于发表的导出结果。

快速入门

  1. 打开树文件，或将其拖放到输入框中。
  2. 选择布局（Rectangular、Circular 或 Unrooted）。
  3. 点击运行进行渲染 — 参数更改后会自动更新。
  4. 点击导出图像，保存为 SVG、PDF 或 PNG。

树选项

布局 Rectangular — 标准系统发育图（朝右）
Circular — 径向系统发育图，适合大型树
Unrooted — 等角无根布局
定根 None — 按树的原样使用
Midpoint — 以最长分支的中点定根
Outgroup — 在指定的末端分类单元上定根
显示支持值 在内部节点显示自举 / 后验概率，保留 小数精度和 IQ-TREE SH-aLRT/UFBoot 标签（例如 98.2/100）
显示比例尺 显示进化距离比例尺
对齐末端标签 在矩形布局中右对齐末端标签
使用枝长 按枝长比例绘制分支（取消勾选可得到分支图）

样式选项

末端字号— 叶标签的字号（6–36 px）
节点大小— 内部节点圆点的大小（0 = 隐藏）
枝宽— 分支线条粗细（1–10 px）
支持值字号— 支持值标签的字号（6–24 px）

画布控制

宽度 / 高度：自动值会根据末端数量和标签长度自适应，也可直接输入像素值。 叶间距：自动调整尺寸时使用的末端最小间距。 标签间距：末端标签与分支之间的距离。

参数变化后会在短暂停顿后刷新。渲染期间仍会保留之前的预览，且对同一文件的更新会保留缩放和平移状态。

适应 / 100%— 完整显示树 / 按原始 SVG 尺寸显示
+ / −— 以视图中心为中心放大 / 缩小
滚轮— 放大 / 缩小
单击并拖动— 平移视图

预览使用矢量 SVG 图形，缩放时文字和分支保持清晰。

导出格式

SVG— 可编辑的矢量图形（推荐）
PDF— 可直接用于发表的文档
PNG— 栅格图像（300 DPI）

末端名称映射

提供两列的映射文件（CSV / TSV / TXT / Excel），即可用自定义名称 替换树的末端标签：

格式old_name,new_name — 每行一对
折叠区域展开“末端名称映射”，然后使用其中的浏览按钮 或拖放一个映射文件。折叠该区域后，映射仍然生效。

只有映射文件中列出的名称会被更改，其他名称保持原样。

输入面板会报告已匹配的末端、未使用的映射条目以及未更改的名称。 无效的映射和映射后重复的名称必须修正后，才能渲染或导出。

使用技巧

  • 文件可以直接拖放到输入框中。
  • 树格式（Newick / Nexus）会根据文件扩展名自动检测。
  • 对于大型树，Circular 布局能更有效地利用空间。
  • 导出的 SVG 文件可在 Inkscape 或 Illustrator 中进一步编辑。
