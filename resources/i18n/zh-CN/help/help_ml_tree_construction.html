最大似然树构建（IQ-TREE） — 构建系统发育树

本工具有什么用？
使用内置的 IQ-TREE 3 可执行程序推断最大似然系统发育树。 支持分区感知模型、超快自举以及自动模型选择。

快速入门

  1. 选择比对文件，或点击示例。
  2. 可选：为多基因分析选择分区文件。
  3. 保持默认值（AUTO / TEST / UFBoot 1000），或调整参数。
  4. 点击运行。

参数

  • 序列类型 — AUTO（推荐）、DNA、AA、CODON、BIN 或 MORPH。
  • 模型 — 保留 TEST 即可自动选择模型。也可指定例如 GTR+G、LG+G+I。
  • 线程数 — CPU 线程数（默认 2，最大不超过 CPU 核心数）。
  • 前缀 — 输出文件：prefix.treefile 等。留空 = 使用输入文件名。
  • 外群 — 可选的逗号分隔分类单元（例如 taxonA,taxonB）， 用于指定树的根（IQ-TREE -o）。

自举与分支支持

  • UFBoot — 超快自举，快速且可靠。推荐：1000。
  • UFBoot + SH-aLRT — 两种检验均使用所选的重复次数。
  • 标准自举 — 经典方法，速度较慢；默认 500 次重复。
  • 自举重复次数 — UFBoot 模式默认 1000，Standard 模式默认 500；设为 0 会同时禁用自举与 SH-aLRT。

输出文件

  • .treefile — 得分最高的 ML 树（Newick 格式）。
  • .iqtree — 完整分析报告。
  • .contree — 共有树（若启用了自举）。

使用技巧

  • 对大多数数据集：AUTO / TEST / UFBoot 1000 是不错的起点。
  • 先用 trimAl 修剪比对，可获得更干净的树。
  • 使用系统树可视化查看得到的树。
