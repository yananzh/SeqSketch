去重 — 移除重复序列

本工具有什么用？
它扫描你的 FASTA 文件并移除重复条目。你可以按 ID（序列头名称相同）或按序列内容（碱基或残基完全相同）进行去重。

快速入门

  1. 选择一个 FASTA 文件，或点击示例。
  2. 选择去重依据：Sequence ID 或 Sequence content。
  3. 如需按 ID 去重，可选择保留策略。
  4. 点击预览，查看将移除多少条重复记录。
  5. 选择输出文件，然后点击运行。

应使用哪种模式？

模式作用适用情况
Sequence ID 每个唯一的序列头名称仅保留一条记录 不同 ID 指向相同的序列，且你希望保留它们；你只想移除意外产生的序列头重复。
Sequence content 每个唯一的序列字符串仅保留一条记录 你需要一个真正无冗余的数据集，不论序列头名称如何，每条序列都只出现一次。

保留策略（仅 ID 模式）

当多条记录共享同一 ID 时，应保留哪一条？

  • Keep first — 保留文件中首次出现的记录（默认）。
  • Keep longest — 保留序列最长的记录。适用于存在部分或截短重复记录的情况。
  • Keep shortest — 保留序列最短的记录。

其他选项

  • 忽略大小写 — 将 'GeneA' 与 'genea' 视为同一 ID。仅在 Sequence ID 模式下可见。
  • 导出被移除的序列 — 将被移除的序列保存到配套的 _removed 文件中（扩展名与输出文件相同），便于检查被过滤掉的内容。

使用技巧

  • 务必先预览，查看将移除多少条重复记录。
  • 先运行 FASTA 统计，检查源文件中是否存在重复 ID——其中的重复 ID 数量与本工具在 ID 模式下找到的数量一致。
  • 处理不熟悉的数据时，请使用导出被移除的序列，以确认没有误删重要序列。
