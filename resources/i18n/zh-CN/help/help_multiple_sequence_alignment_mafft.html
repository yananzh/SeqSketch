多序列比对 — MAFFT

本工具有什么用？
使用内置的 MAFFT 引擎对 ≥ 2 条 DNA 或蛋白质序列进行比对。 提供三种策略，从快速的启发式方法到高精度的迭代优化，可按需选择。

快速入门

  1. 粘贴 ≥ 2 条 FASTA 序列，或拖放一个文件。
  2. （可选）选择输出文件 — 留空时会自动生成带时间戳的文件名。
  3. 选择比对策略（Auto 适用于大多数情况）。
  4. 点击运行 — 结果会自动写入输出路径。

单文件与批量多文件

  • 单文件 — 对一个多序列 FASTA 输入进行比对，并保存到所选的输出文件。
  • 批量多文件 — 处理多个所选的 FASTA 文件， 可通过 {stem}、{method}、{ext} 占位符自动命名。

比对策略

Auto→ 均衡的默认策略，适用于大多数数据集
FFT-NS-2→ 快速的渐进式方法，适合大型数据集
L-INS-i→ 精度最高，采用迭代优化；适合分化程度较高的序列

序列顺序

  • Input sequence order — 将比对后的序列恢复为与原始输入一致的顺序。
  • MAFFT output order — 保留 MAFFT 返回的顺序。

输出

  • 比对结果以 FASTA 格式直接写入所选路径。
  • 批量模式支持 FASTA、CLUSTAL 和 Summary 输出格式。

使用技巧

  • 对于大多数数据集，Auto 模式会自动选择合适的策略。
  • 对于分化程度较高的序列，使用 L-INS-i 可获得高质量比对（速度较慢但更准确）。
  • 对于注重速度的大型数据集，使用 FFT-NS-2。
  • 比对完成后，可使用 trimAl 去除比对质量较差的列，再使用 IQ-TREE 构建系统发育树，或使用 MSA 可视化查看结果。
