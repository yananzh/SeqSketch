简化序列头 — 生成简洁的序列 ID

本工具有什么用？

来自 NCBI 或 UniProt 等数据库的 FASTA 文件，其序列头往往很长，充满各种注释。本工具将其缩短为简洁、可预测的 ID，使下游工具（比对软件、系统发育软件、可视化工具）不会因此出错或误读。

什么是"序列头"？

FASTA 序列头在 > 之后的第一个空白字符处被切分。第一个空格之前的部分是 ID（本工具要简化的部分）；之后的部分是 Description（描述）。例如：

>NM_001101.5 Homo sapiens protein kinase
 |----ID----| |-------描述--------|

除非勾选了保留描述，否则输出中会去掉描述部分。所有模式都基于完整的序列头行（ID + 描述）进行处理。

使用示例数据试一试

点击文件输入框旁的示例按钮，它会载入 simple_header.fasta——包含 tr|acc|entry 格式的真实 UniProt/TrEMBL 序列头。该文件非常适合用来测试每种简化模式。

使用内置数据的示例

载入示例文件后，对下面的序列头尝试这些设置：
>tr|A0AAI7ZCJ9|A0AAI7ZCJ9_XANAC Pyruvate dehydrogenase ...：

第一个单词                        →  tr|A0AAI7ZCJ9|A0AAI7ZCJ9_XANAC
分隔符 "|" 第 2 个字段            →  A0AAI7ZCJ9
分隔符 "|" 第 3 个字段            →  A0AAI7ZCJ9_XANAC_Pyruvate_...（最后一个字段保留其余部分）
保留 2 个单词                     →  tr|A0AAI7ZCJ9|A0AAI7ZCJ9_XANAC_Pyruvate
正则表达式 tr\|([^|]+)\|            →  A0AAI7ZCJ9
正则表达式 ([A-Z0-9]{10}_[A-Z]+)   →  A0AAI7ZCJ9_XANAC

应选择哪种模式？

观察你的序列头格式，选择对应的规则：

你的序列头形如→ 使用此模式
>NM_001101.5 Homo sapiens gene
（登录号后跟一个空格）		 → First word
>tr|A0AAI7ZCJ9|A0AAI7ZCJ9_XANAC
（UniProt，以竖线分隔的字段）		 → Regex tr\|([^|]+)\|（字段 3 会吞掉描述部分）
>contig_123 length=5000 cov=10.5
（以空格分隔的标记，保留前几个）		 → Keep first N words
>lcl|seq_001 gene:kinase
（结构化，但不完全基于分隔符）		 → Regex capture

快速入门

  1. 点击示例载入内置的 simple_header.fasta，或浏览选择你自己的 FASTA 文件。
  2. 从下拉框中选择简化模式——下拉框旁会显示带示例的提示。
  3. 填写所需参数（分隔符、字段序号、正则表达式或单词数）。
  4. 点击预览，在处理整个文件之前检查前 5 个 ID。
  5. 调整选项（大小写、前缀/后缀、保留描述等）。
  6. 点击运行，简化每个序列头并保存结果。

各模式详解

1. First word
只保留序列头中第一个以空白分隔的单词。

输入 >NM_001101.5 Homo sapiens protein kinase
输出 >NM_001101.5

2. Delimiter field
按某个字符（例如 |、_、:）拆分序列头，并选取一个字段。字段序号从 1 开始（1 表示起始 > 之后的第一个字段）。

输入 >tr|A0AAI7ZCJ9|A0AAI7ZCJ9_XANAC Pyruvate ...
分隔符|
字段序号 2→ A0AAI7ZCJ9
字段序号 3→ A0AAI7ZCJ9_XANAC

3. Keep first N words
取前 N 个以空白分隔的单词，并用下划线连接。适用于保留物种名加登录号前缀，同时去掉重复的注释文字。

输入 >Salmon_salar_cytb mitochondrial cytochrome b
保留 2 个单词 → Salmon_salar_cytb_mitochondrial

4. Regex capture
对序列头应用正则表达式。第一个捕获组 (...) 将成为新的 ID。若不含捕获组，则整个匹配结果成为 ID。未匹配的序列头保留原始 ID，并记录一条警告。

UniProt / NCBI 常用正则表达式：

模式提取内容
tr\|([^|]+)\| UniProt TrEMBL 登录号——第 2 个以竖线分隔的字段
sp\|([^|]+)\| UniProt Swiss-Prot 登录号
ref\|([^|]+)\| 来自 gi|...|ref|... 序列头的 NCBI RefSeq 登录号
([A-Z0-9]{10}_[A-Z]+) UniProt TrEMBL 条目名（例如 A0AAI7ZCJ9_XANAC）
GN=(\w+) 注释部分中的基因名

提示：运行前，可使用在线正则表达式测试工具（例如 regex101.com）构建并验证你的模式。

其他选项

大小写转换
将所有简化后的 ID 强制转为 UPPERCASE（大写）或 lowercase（小写），或保持 As-is（原样）。区分大小写的下游工具（例如某些系统发育软件）通常要求统一的大小写。

前缀 / 后缀
在每个简化后的 ID 之前或之后添加固定文本（例如样本编号或物种代码）。示例：对 NM_001101.5 添加前缀 S1_，得到 S1_NM_001101.5。

保留描述
默认情况下，第一个空格之后的文本（序列头中的“描述”或“注释”部分）会与简化后的 ID 一起被去掉。勾选此项可将描述文本保留在新的、更短的 ID 之后。当下游注释需要这些信息时很有用。

自动编号重复 ID
若两个或多个原始序列头简化后得到相同的 ID（即“冲突”），此选项会追加 _2、_3 等后缀，而不是拒绝保存。未勾选时，重复 ID 会使运行因错误而停止，以便你手动修正问题。

导出 ID 映射报告
在输出文件旁保存一个 TSV 文件，列出每个旧 ID、其新 ID、是否发生变化，以及由哪种模式生成。这对于审计追踪，以及重新关联存储在旧 ID 下的注释信息至关重要。

使用技巧

  • 处理大文件前务必先预览——正则表达式的拼写错误和错误的字段序号很容易被忽略。
  • 先运行 FASTA 统计，检查源文件中是否存在重复 ID；如果不知道输入中本就存在重复，输出中的重复将更难排查。
  • 处理将用于发表或与合作者共享的文件时，请启用导出 ID 映射报告。
  • 若没有任何 ID 发生变化，请检查操作日志中关于分隔符不匹配或正则未匹配的警告——工具无法应用所选规则时会保留原始 ID。
  • 使用大小写选项，在输入区分大小写的流程之前统一混合大小写的登录号。
