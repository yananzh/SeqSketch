密码子使用分析 — 综合密码子偏好工具包

本工具有什么用？
它对蛋白质编码序列（CDS）进行完整的密码子使用分析。工具计算多项关键指标，包括 RSCU（相对同义密码子使用度）、 ENC（有效密码子数）、CAI（密码子适应指数），以及每个密码子位置上的 GC 含量。结果分布在五个交互式标签页中， 包含可排序的表格和可用于发表的 Matplotlib 图表。

快速入门

  1. 在输入框中粘贴一条或多条 FASTA 格式的 CDS 序列，或点击载入文件
  2. 为你的生物选择合适的遗传密码表（默认：Standard）
  3. 可选：选择CAI 参考生物以计算密码子适应指数
  4. 选择阅读框（默认 +1 适用于大多数 CDS 输入）
  5. 点击运行（右下角），然后浏览五个结果标签页

关键指标说明

指标含义解释
RSCU相对同义密码子使用度（Relative Synonymous Codon Usage）数值 > 1 = 使用过多，< 1 = 使用不足；理想值 = 1.0（无偏好）
ENC有效密码子数（Effective Number of Codons）标准密码表：20–61。其他密码表，或任一简并类别缺少至少含两个密码子的家族时显示 N/A。序列较短时估计值可能不稳定。
CAI密码子适应指数（Codon Adaptation Index）取值范围 0–1；数值越高表示与参考生物的翻译适应性越好
稀有密码子RSCU < 0.3 的密码子大量稀有密码子可能会限制异源宿主中的蛋白质表达
GC / GC3整体 GC% 与第 3 密码子位置的 GC%GC3 是突变偏好的敏感指标；GC3 较低通常与翻译选择相关

结果标签页

  • 摘要 — 当前序列的关键统计信息，以及使用最多的前 10 个密码子表格
  • 密码子 — 完整的 64 个密码子表，包含计数、每千个密码子的频率和 RSCU。可按氨基酸（单字母或三字母，例如 L 或 Leu）筛选，隐藏计数为零的密码子，或切换是否显示终止密码子
  • RSCU — 按氨基酸分组的 RSCU 值柱状图，每个同义密码子对应一根柱
  • GC/中性分析 — 所选序列的 GC(All)/GC1/GC2/GC3/GC12 柱状图，以及 GC12 对 GC3 的中性图（斜率 ≈ 1 = 中性进化；斜率 < 1 = 选择约束）
  • 比较 — 每条序列的表格（ENC、CAI、GC%、GC3%）以及 Nc 图（ENC 对 GC3），用于判断突变压力与选择压力

遗传密码表

本工具支持 11 种 NCBI 遗传密码表。最常用的替代密码表如下：

  • 1 - 标准（通用） — 大多数核基因组
  • 2 - 脊椎动物线粒体 — UGA = Trp（非终止），AUA = Met，AGA/AGG = 终止
  • 5 - 无脊椎动物线粒体 — 节肢动物 mtDNA 中常用
  • 11 - 细菌、古菌和植物质体 — 大多数密码子与 Standard 相同

CAI 参考表

密码子适应指数（CAI）将你的序列的密码子使用情况与参考生物中高表达基因的密码子使用情况进行比较。 内置参考为：Human、E. coli K-12、S. cerevisiae、C. elegans、A. thaliana 和 M. musculus （RSCU 表源自全基因组密码子使用数据）。CAI 值 > 0.8 表示与该参考具有良好的适应性。

阅读框

本工具在三个正向阅读框之一中翻译你的序列。对于典型的 CDS 输入请使用阅读框 +1；如果序列可能存在错位或包含替代起始位点，请尝试 +2 和 +3 阅读框。

使用技巧

  • 点击示例载入真实的细菌 spoT CDS，快速试用
  • 密码子表支持排序——点击任意列标题即可重新排列行
  • 使用氨基酸筛选（例如 "L"、"Leu" 或 "L,M"）聚焦特定密码子家族；隐藏计数为零的密码子默认开启
  • 输入多条序列时会出现选择器，比较标签页会提供每条序列的摘要和 Nc 图
  • 使用导出图表将当前图表（RSCU / GC/中性分析 / 比较）保存为 PNG、PDF 或 SVG
  • 清空会重置输入和所有结果视图
  • 以 CSV 形式导出数据——文件包含每条序列的摘要以及完整的密码子使用表
  • 若要分析全基因组的密码子使用，请将同一基因组的 CDS 序列合并为一个 FASTA 文件
