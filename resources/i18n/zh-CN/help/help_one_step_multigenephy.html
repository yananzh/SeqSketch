One Step MultiGenePhy — 自动化系统发育基因组学流程

本工具有什么用？
导入按基因组织的 Excel 工作簿，一步运行完整的 获取 → 标准化 → 比对 → 修剪 → 拼接 → 建树流程。 支持混合使用 NCBI 登录号与私有序列。

快速入门

  1. 点击示例载入内置演示工作簿，或点击浏览 选择自己的 Excel 文件。点击格式参考可查看预期的 工作簿布局。
  2. 检查自动检测到的工作表和菌株列。在 基因列表中，取消勾选所有并非基因的元数据列。
  3. 若任一单元格包含登录号，请输入你的 NCBI 邮箱。
  4. 点击校验输入，检查文件格式和外部工具路径。
  5. 选择输出目录，然后点击运行。

工作簿格式

  • 第一行 = 表头行。
  • 其中一列 = 菌株标识（例如 Species）。
  • 其余列 = 基因位点（例如 ITS、TEF1、RPB2）。
  • 每个基因单元格：NCBI 登录号、原始序列或空白（缺失数据）。

流程步骤

  1. 导入 — 解析 Excel，区分登录号与原始序列。
  2. 获取 — 下载 NCBI 序列，按基因标准化为 FASTA。
  3. 比对 — 对每个基因分别运行 MAFFT。
  4. 修剪 — 运行 trimAl，去除比对质量较差的列。
  5. 拼接 — 合并为超级矩阵 + NEXUS 分区文件。
  6. 建树 — 使用分区感知模型运行 IQ-TREE。
  7. 汇总 — 生成 HTML 报告、清单和日志。

参数

  • MAFFT — Auto（自动选择）、Local Pair（局部比对）、Global Pair（全局比对）或 Conserved Region（保守区域比对）。
  • trimAl — automated1（启发式）、gappyout（自适应空位移除）、strict/plus（保守的空位+相似性）、nogaps（移除全空位列）。
  • 线程数 — 供 IQ-TREE 使用的 CPU 线程数（默认 2，最大可至你的 CPU 核心数）。
  • IQ-TREE 自举 — UFBoot（超快，推荐 1000）、UFBoot + SH-aLRT（分支检验）或 Standard bootstrap（默认 500）。切换模式时该值会自动填入；设为 0 表示关闭自举。
  • 每个基因的比对结果和修剪后文件始终保留在各阶段文件夹中，便于检查。
  • 跳过已完成的步骤 — 复用同一输出文件夹中此前运行的成果：

    复用要求输入一致，且产物哈希已验证。若产物缺失、发生变化或为较早的未验证版本， 运行会停止并给出说明。若要重新构建，请显式选择 From scratch。选择任一复用模式都会运行只读的 后台预检；结果会显示在对话框中，说明哪些步骤将被跳过，或为何无法复用。 输入或参数变化会自动重新检查复用条件。相同的结果不会重复显示。运行开始时还会再次检查文件。 仅建树的运行允许修改自举设置和线程数，而无需重复之前的步骤。基因显示名会映射为安全的唯一 ID； 原始名称映射保存在 run_manifest.json 中。

    From scratch（默认，完整流程）、From align/trim（复用 01_normalized，跳过网络获取）或 From tree （复用 04_concat，跳过获取/比对/修剪/拼接，仅重新运行 IQ-TREE）。如果修改了工作簿，请选择 From scratch。

输出文件

  • 05_iqtree/final.treefile — Newick 格式的最佳最大似然树。
  • 04_concat/supermatrix.fasta + partitions.nex — 拼接后的比对及其 NEXUS 分区文件。
  • 06_reports/run_report.html — 含系统树和统计信息的交互式 HTML 摘要。
  • 06_reports/run_manifest.json — 用于可复现性的文件清单。

使用技巧

  • 先点击格式参考查看预期的工作簿布局，再点击示例载入演示工作簿。
  • 菌株名称只应包含字母、数字和下划线。
  • 运行前使用校验输入，可及早发现格式问题。
  • 对于大型数据集，可增加线程数以加快 IQ-TREE（比对本身以单线程运行）。
  • 运行完成后，点击查看系统树可视化结果。
  • 预先修剪过的输入序列通常能获得更好的比对结果。
