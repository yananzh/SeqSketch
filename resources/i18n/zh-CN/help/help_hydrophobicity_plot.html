疏水性图 — 滑动窗口分析

本工具有什么用？
它使用滑动窗口为每个残基位置计算疏水性得分，然后沿蛋白质序列绘制曲线。 对于 Kyte-Doolittle 类标度，正值表示疏水区域，负值表示亲水区域（Hopp-Woods 为反向标度，参见下方“标度”）。

快速入门

  1. 将蛋白质序列（原始序列或 FASTA）粘贴到输入框中，或点击示例载入一条序列。
  2. 选择疏水性标度（Kyte-Doolittle 为经典默认值）以及窗口大小（9-15 适用于大多数蛋白质）。
  3. 点击绘图绘制曲线，然后点击导出图表保存图像。

标度

  • Kyte-Doolittle — 经典的疏水性标度。数值 > 0 为疏水。广泛用于识别跨膜螺旋和信号肽。
  • Hopp-Woods — 亲水性 / 抗原性标度。正值表示可能为抗原表位的区域。
  • Eisenberg — 共识归一化疏水性。在多个实验数据集中保持平衡。
  • Engelman (GES) — 针对跨膜螺旋预测优化，使用 Goldman-Engelman-Steitz 标度。

使用技巧

  • 使用 Kyte-Doolittle 或 Engelman 标度寻找跨膜螺旋时，可将窗口 = 19–21
  • 进行一般的疏水性分析时，可使用窗口 = 7–9
  • 若得分在 20 个以上残基中持续高于约 1.6（Kyte-Doolittle），则提示存在跨膜螺旋。
  • 仅分析第一条 FASTA 记录 — 多记录文件应先拆分后再使用
  • 点击导出图表可将图像保存为 PNG / PDF / SVG
