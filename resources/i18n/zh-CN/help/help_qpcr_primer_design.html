qPCR 引物设计 — 通过 Primer3 设计 PCR 引物

本工具有什么用？
使用 Primer3 引擎为定量 PCR（qPCR / 实时 PCR）设计最优引物对。它会在你的模板 DNA 中搜索满足适合 qPCR 的严格 Tm、GC% 和产物长度约束的引物对。

快速入门

  1. 输入模板 DNA 序列 — 粘贴原始序列或 FASTA 格式（允许碱基 A/C/G/T/U/N），或点击示例载入 HBB 外显子 1。
  2. 如需调整，可修改参数 — 默认值（产物 80-150 bp、Tm 57-63°C、GC 40-60%）适用于大多数 qPCR 应用。
  3. 点击“运行”，在后台启动 Primer3（模板长度至少为 50 bp）。
  4. 在表格中查看结果 — 下方的图谱会显示每个返回的引物对；点击某一行即可刷新。
  5. 将结果导出为 Excel，供后续使用。

参数指南

产物长度（最小/最大）预期扩增子长度（bp）。qPCR：70-200 bp 时效率最佳。
引物对数量返回多少对引物。数值越大，可供选择的候选越多。
长度（最小/最优/最大）引物长度（nt）。典型值：18-25 nt。必须满足最小值 ≤ 最优值 ≤ 最大值。
Tm（最小/最优/最大）解链温度（°C）。qPCR 典型范围：57-63°C。最小值 ≤ 最优值 ≤ 最大值。
GC%（最小/最优/最大）GC 含量百分比。典型值：40-60%。最小值 ≤ 最优值 ≤ 最大值。

高级参数

盐浓度（单价）Na+/K+ 浓度（mM）。影响 Tm 计算。标准 PCR：50 mM。
Mg²+镁离子浓度（mM）。影响 Tm 和特异性。qPCR 典型值：2-3 mM。

结果解读

  • 引物对编号 — 按 Primer3 惩罚分数排序（1 = 最佳）。
  • 正向 / 反向 — 正向（sense）或反向（antisense）引物。
  • 位置 — Primer3 报告的、以 0 为起始的模板坐标：正向引物为最靠近 5' 端的碱基，反向引物为最靠近 3' 端的碱基。因此反向引物的结合跨度从 位置−长度+1 到 位置。
  • 长度 — 引物长度（核苷酸数）。
  • Tm — 解链温度。正向与反向引物的 Tm 差值应在 2°C 以内。
  • GC% — GC 含量。40-60% 对 qPCR 最佳。
  • 产物长度 — 预期扩增子长度（bp）。

结合位点图谱 — 蓝色箭头 = 正向引物，橙色箭头 = 反向引物，按比例绘制在模板线上。

故障排查

“未找到引物对”

  • 放宽约束 — 扩大 Tm、GC% 或长度范围。
  • 增大产物长度范围（例如 70-200 bp）。
  • 增加请求的引物对数量。
  • 确认模板包含有效碱基（仅限 A/C/G/T/U/N）。
  • 对于较短的模板（<100 bp），请缩小产物长度范围。
  • 确保已安装 primer3-py：pip install primer3-py

设计之后 — 分析你的引物

打开 引物设计 → 引物分析，检查结果中任意引物对的发夹结构、自身二聚体和交叉二聚体特性。
