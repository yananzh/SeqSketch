FASTA ↔ 表格 — 在文件与电子表格之间转换

本工具有什么用？
同一个标签页中包含两种转换：

  • FASTA → Table — 将每条记录导出为 CSV、TSV 或 Excel 表格中的一行。
  • Table → FASTA — 根据包含 ID 列和 Sequence 列的电子表格重建 FASTA 文件。

FASTA → Table 输出列

列内容
ID序列标识符 — 序列头中第一个空格之前的文本
Description序列头中第一个空格之后的其余部分（若没有则为空）
Length碱基或氨基酸的数量
Sequence完整序列

快速入门

  1. 选择方向。
  2. 选择输入文件（FASTA，或 CSV / TSV / Excel）。
  3. 若为 FASTA → Table 方向，选择表格格式。
  4. 点击预览进行检查，然后点击运行。

表格 → FASTA 的列名

工具按列名查找列（不区分大小写）：

角色可接受的列名
ID（必需）id、sequence_id、 seqid、accession、header
Sequence（必需）sequence、seq、 dna、rna、protein、aa
Description（可选）description、 desc、annotation

转换规则

  • ID 或序列为空的行会被跳过。
  • 序列列中的空格和换行会被自动移除。
  • 描述单元格为空时，生成的 FASTA 记录不含描述部分。
  • 列名匹配不区分大小写——ID、id 和 Id 均可识别。
  • 重建 FASTA 时，输入表格中多余的 Length 列会被忽略；长度始终根据序列重新计算。

使用技巧

  • Excel 的导出与导入需要 openpyxl——本应用已内置该库。
  • 可以在 Excel 中方便地编辑或检查序列，然后用 Table → FASTA 转换回去。
  • 转换回去后，运行 FASTA 统计，核对长度和序列字符集。
  • 点击示例——在 FASTA → Table 模式下会载入内置的 B.subtilis_pro.fasta；在 Table → FASTA 模式下会载入 simple_table.csv。
