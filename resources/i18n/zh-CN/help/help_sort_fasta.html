排序 FASTA — 重新排列序列

本工具有什么用？
按三个依据之一（序列 ID、序列长度或 GC 含量），以升序或降序重新排列 FASTA 文件中的记录。序列数据和序列头都不会被修改。

排序依据说明

依据顺序示例
序列 ID字母顺序（A→Z 或 Z→A） >chr10_sample 排在 >seq1 之前
序列长度最短的在前，或最长的在前 6 nt 排在 8 nt 之前
GC 含量GC 含量最低的在前，或最高的在前 33% 排在 50% 之前，50% 排在 100% 之前

稳定排序

排序是稳定的：依据值相同的记录，保持其原有的相对顺序。按长度排序时，两条长度均为 8 nt 的序列，会保持它们在输入文件中的先后顺序。

快速入门

  1. 选择一个 FASTA 文件（或点击示例，载入内置的 B.subtilis_pro.fasta 蛋白质数据集）。
  2. 选择排序依据和顺序（升序 / 降序）。
  3. 点击预览 — 将显示新顺序下的前 8 条记录，以及记录总数。
  4. 选择输出文件，然后点击运行进行保存。

典型用途

  • 按长度 — 发现异常短或异常长的序列；这些通常是组装错误或截断的记录（质量控制）。
  • 按 ID — 为多基因系统发育分析合并各基因文件之前，让每个基因文件中的样本顺序保持一致。
  • 按 GC 含量 — 极端的 GC 值可能提示污染或 PCR 伪迹；排序后，它们会集中在文件的开头或末尾。
  • 拆分之前 — 先排序，再运行拆分 FASTA，使每个部分都遵循所选顺序。

使用技巧

  • GC 含量基于整条序列计算；对于蛋白质文件，该值通常没有参考意义。
  • 排序是确定性的 — 相同的文件和设置始终产生相同的输出，有助于结果复现。
  • 只有顺序会改变：序列头、描述和序列都会按读取时的原样写入。
