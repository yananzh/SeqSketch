GC 含量 / GC 偏斜图 — 滑动窗口分析

本工具有什么用？
它使用滑动窗口计算 DNA 序列的 GC 含量和 GC 偏斜，并绘制这两条曲线。GC 含量反映碱基组成的变化；GC 偏斜反映复制过程中因突变速率不同而产生的链不对称性， 是定位细菌基因组复制起点（oriC）和终点的经典方法（Lobry 1996，Grigoriev 1998）。

快速入门

  1. 选择一个 FASTA 文件（通过浏览或拖放），或点击示例载入 pBR322 质粒
  2. 调整窗口大小，以获得所需的平滑程度
  3. 点击绘图——使用图表上方的三个按钮（GC 含量 / GC 偏斜 / 累积 GC 偏斜）切换视图

指标说明

指标公式范围解释
GC 含量(G+C)/(A+T+G+C)0–100%整体 GC 丰富度；编码区往往富含 GC，基因间区往往富含 AT
局部 GC 偏斜(G−C)/(G+C)−1 至 +1正值 = G 过量（前导链）；负值 = C 过量（滞后链）。链特异性的突变和选择偏好会产生偏斜
累积 GC 偏斜Σ (G−C)/(G+C)不定沿基因组的运行总和。V 形曲线在 oriC 附近由负值转为正值。全局最小值 ≈ oriC；全局最大值 ≈ terC

滑动窗口的工作原理

长度为 W bp 的窗口以 S bp 的步长在序列上滑动。 在每个位置上，计算以该位置为中心的窗口内碱基的 GC 含量和 GC 偏斜。 采样位置之间的值通过线性插值得到平滑曲线。

  • 较大的窗口（500–1000 bp）可平滑局部噪声，便于观察基因组尺度的模式
  • 较小的窗口（20–100 bp）可揭示基因水平的 GC 变化
  • 步长 = 窗口大小 时窗口不重叠（速度更快）；步长 < 窗口大小 时窗口重叠（曲线更平滑）

累积 GC 偏斜与 oriC 检测

在大多数细菌中，前导链上 G 相对 C 不断积累（正偏斜），而滞后链上 C 相对 G 不断积累（负偏斜）。 由于复制从单一起点双向进行，链的不对称性在 oriC 和 terC 处发生反转。 将 GC 偏斜沿基因组累加后，会得到特征性的 V 形曲线：

  • 全局最小值（累积值最低处）→ 推定的 oriC
  • 全局最大值（累积值最高处）→ 推定的 terC
  • 两个极值之间的差异反映了链偏好的强度

该方法在完整或接近完整的细菌染色体上效果最好。质粒和不完整的序列可能不会呈现清晰的模式。

序列类型推荐窗口推荐步长

示例与应用场景

  • oriC 预测——载入完整的细菌基因组，查看累积 GC 偏斜，将窗口设为 1001，然后点击绘图。红色/绿色标记指示预测的 oriC/terC
  • 基因组质量检查——嘈杂或平坦的累积偏斜曲线可能提示组装错误、contig 方向错误或基因组不完整
  • 质粒分析——即使是小型复制子，局部 GC 偏斜也能揭示前导链/滞后链的边界
  • 水平基因转移检测——GC 含量明显偏离基因组均值的区域通常提示近期获得的 DNA

使用技巧

  • 使用示例按钮载入 pBR322 质粒（4,361 bp）——这是一个紧凑的环状复制子，其前导链/滞后链偏好非常明显
  • 使用保存图像将当前视图导出为 PNG/PDF/SVG
  • 对于多 contig 的组装结果，请对每个 contig 分别运行本工具
  • 若所选文件包含多条序列，则使用第一条 FASTA 记录
  • 每个窗口内的 N 碱基在 GC 计算中被忽略
