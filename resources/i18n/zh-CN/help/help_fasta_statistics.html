FASTA 统计 — FASTA 文件的序列统计信息

本工具有什么用？
它会扫描你的 FASTA 文件并生成质量报告，帮助你在问题影响后续分析之前及时发现。可以把它看作序列数据的健康检查。

快速入门

  1. 选择一个 FASTA 文件（支持拖放）。
  2. 选择统计报告的保存位置。
  3. 点击运行。
  4. 查看摘要面板以及保存的 TSV 报告。

支持的文件格式

.fasta · .fa · .fas · .fna · .ffn · .faa · .frn · .txt

指标说明

序列总数
文件中的 FASTA 记录数（以 > 开头的条目）。

总长度 / 平均长度 / 最小长度 / 最大长度
序列长度（以碱基或残基计）的总和、平均值、最短值和最长值。最小值与最大值之间差距很大，可能表示数据类型混杂或条目被截断。

序列类型
序列看起来是 DNA/RNA、蛋白质还是两者混合。本工具根据每条序列中出现的字符集合进行推断。

GC 含量
G 和 C 碱基所占的百分比（仅适用于 DNA/RNA）。GC 含量过高或过低，会影响 PCR 引物设计、测序覆盖度偏差以及二级结构。

模糊碱基数
IUPAC 模糊碱基代码的数量：R、Y、M、K、S、W、B、D、H、V。它们表示测序仪无法确定为单一碱基的位置（例如 R = A 或 G）。大量模糊碱基可能提示低质量区域。

N 含量
N 碱基的总数及其总体百分比。N 表示完全未知的碱基，常见于无法补全缺口的基因组组装中。N 含量高通常说明组装不完整或属于草图组装。

无效字符数
不属于标准核苷酸或蛋白质字母表的字符（例如序列中的数字、标点或空白）。这些字符可能导致比对和分析工具出错。

重复 ID 数
与较早记录共用同一 ID 的额外记录数（同一 ID 出现三次则计为 2）。重复 ID 会让许多生物信息学工具产生混淆，通常应在进一步分析前解决。

输入示例

>contig_1 length=5000
ATGCNNNNACTG...
>contig_2 length=3200
GGTACCATGGC...

输出

本工具会写出一份以制表符分隔的（.txt）报告，包含两部分：

  • 摘要部分 — 屏幕面板中显示的全局指标
  • 逐序列表格 — 每条 FASTA 记录一行，包含 ID、长度、类型、GC%、N 数量、模糊碱基数、无效字符以及描述长度

使用技巧

  • 在将每个 FASTA 文件交给比对、组装或注释流程之前，都应先运行本工具。
  • 如果序列类型显示为“混合/未知”，请查看逐序列表格，找出哪些记录的字母表不符合预期。
  • 可在 Excel 或 Python 中使用逐序列 TSV，按长度或 GC 含量筛选异常值。
