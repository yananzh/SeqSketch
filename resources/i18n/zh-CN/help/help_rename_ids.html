重命名 ID — 批量重命名 FASTA 序列 ID

本工具有什么用？
它借助映射文件批量重命名 FASTA 序列 ID。你只需准备一个两列的表格（旧 ID → 新 ID），工具即可一次性完成所有替换。

快速入门（新手）

  1. 使用浏览按钮或拖放方式选择一个 FASTA 文件。
  2. 点击导出当前 ID——这会生成一个模板文件（Excel、CSV 或 TSV），列出 FASTA 中的每个 ID，并附带一个空的“新 ID”列。
  3. 用 Excel 或任意文本编辑器打开模板，在第二列填入所需的新 ID。
  4. 保存文件并返回本工具，将编辑后的文件选为 ID 映射文件。
  5. 点击预览，检查前几条重命名结果是否正确。
  6. 选择输出文件，然后点击运行。

映射文件格式

old_idnew_id
sequence_001Gene_A
sequence_002Gene_B
NM_001101.5RefSeq_001

支持的格式：CSV（.csv）、TSV/TXT（.tsv .txt），以及在安装 pandas 后可用的 Excel（.xlsx .xls）。

选项

  • 映射文件包含表头行 — 如果文件没有表头、第一行即为数据，请取消勾选。
  • 冲突时阻止运行 — 若两个旧 ID 映射到同一个新 ID，则停止运行，防止意外产生重复的序列 ID。只有在确认允许重复时才建议关闭。
  • 导出重命名报告 — 保存一个 TSV 文件，列出每条旧→新映射、是否已应用以及原因。

使用技巧

  • 点击示例可载入内置的 gyrB 蛋白质 FASTA 文件及现成的 ID 映射文件（Excel，old_id → new_id），适合第一次尝试。
  • 运行前务必先预览——映射错误很容易被忽略。
  • 只替换主 FASTA ID（第一个空格之前的部分）。默认情况下，输出序列头会去掉原始描述；如需保留，请勾选保留原始描述。
  • 映射文件中未列出的 ID 保持不变。
  • 如果没有任何 ID 与映射文件匹配，则不会写出 FASTA 输出（若已启用该选项，仍会保存重命名报告）。
