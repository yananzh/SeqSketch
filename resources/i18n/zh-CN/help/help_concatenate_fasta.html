合并 FASTA — 合并多个文件

本工具有什么用？
它将多个 FASTA 文件合并为一个输出文件。使用添加文件加入文件，然后点击运行。输出顺序与文件列表中的顺序一致。

快速入门

  1. 点击添加文件，选择一个或多个 FASTA 文件（也可点击示例加入内置样例）。
  2. 文件加入后，列表中会显示每个文件的序列数。
  3. 点击预览，确认所有文件均可读取，并查看序列总数。
  4. 选择输出文件，然后点击运行。

选项

  • 将源文件名添加为 ID 前缀 — 在每个序列 ID 前添加源文件名（不含扩展名），并以 | 分隔。例如，file1.fasta 中的 >NM_001101.5 会变为 >file1|NM_001101.5。
  • 合并后去重 — 从合并结果中移除重复的序列 ID，并保留首次出现的记录。适用于不同文件含有相同 ID 的序列的情况。

适用场景

  • 将染色体水平的组装结果合并为一个全基因组 FASTA。
  • 合并多个基因家族的比对结果。
  • 汇总并行 BLAST 搜索的结果。

使用技巧

  • 文件按列表中的顺序进行合并。
  • 运行前务必先预览，确认每个文件都可以读取。
  • 合并完成后，可使用 FASTA 统计核对合并结果。
  • 如果源文件之间存在相同的序列 ID，请勾选合并后去重，以避免输出中出现重复的序列头。
