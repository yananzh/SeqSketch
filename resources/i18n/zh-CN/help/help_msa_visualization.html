MSA 可视化 — pyMSAviz

本工具有什么用？
使用 pyMSAviz 渲染彩色的多序列比对图，它是对 Matplotlib 的 Python 封装。 非常适合生成达到发表质量的多序列比对图片。

快速入门

  1. 通过浏览载入已完成比对的 FASTA 文件，或直接拖放 （所有序列长度必须相同）。
  2. 选择颜色方案并调整显示选项。
  3. 点击运行 — 渲染出的图会显示在下方可滚动的区域中。
  4. 使用保存图像导出为 PNG、SVG 或 PDF，然后点击 结果文件夹找到已保存的文件。

颜色方案

Clustal→ 经典的 Clustal-X 配色（蛋白质默认）
Zappo→ 按氨基酸理化性质着色
Taylor→ Taylor 残基着色
Hydrophobicity→ 按残基疏水性着色
Nucleotide→ 推荐用于 DNA 比对
Identity→ 按残基保守程度着色
None→ 纯灰色残基

显示选项

  • 序列字符 — 显示/隐藏每个格子中的残基字母。
  • 网格 — 绘制单元格边框。
  • 显示计数 — 沿 x 轴显示列号。
  • 共有序列 — 在比对下方显示共有序列条。
  • 自动排序 — 按与第一条序列的相似度重新排序。
  • 高亮保守列 — 为达到一致性阈值的列添加浅蓝色背景。

使用技巧

  • 先使用多序列比对（Muscle5 / MAFFT）标签页生成比对，再在此处载入 输出文件。
  • 将换行长度设为 0，即可显示为单行连续排列。
  • DPI（默认 150）控制预览清晰度；导出时始终至少使用 300 DPI。
  • 使用保存图像可导出 PNG、SVG、PDF 或 TIFF 格式的高分辨率副本。
