# 合并 MUSCLE 标签页进 MAFFT 标签页 — 实施计划

## 目标
两个重叠的 MSA 标签页（MUSCLE 1384 行 + MAFFT 1213 行）合并为一个带引擎下拉框的标签页。消除复制分叉带来的 bug（MUSCLE 版丢了 stderr 详情、遮蔽了 QThread.finished 信号、单文件无 stop()），减半 UI 维护成本。

## 核心设计：引擎下拉框驱动策略切换
在 MAFFT 标签页的参数区 Row 0 最左侧加 `engine_combo`（"MAFFT" / "MUSCLE v5"）。`currentIndexChanged` 驱动：
- **strategy_combo** 选项切换：MAFFT → [Auto, FFT-NS-2, L-INS-i]；MUSCLE → [Accurate (-align), Fast (-super5)]
- **order_combo** 文案切换："MAFFT output order" ↔ "MUSCLE output order"
- **exe 路径默认值**切换：MAFFT → `_default_mafft_exe()`，MUSCLE → `_load_saved_muscle_path()`
- 批量区同步：`batch_strategy_combo` 同理

## 文件改动清单

### 1. `modules/mafft_alignment_tab.py`（主文件，~1213 → ~1450 行）

**新增导入与助手**（从 MUSCLE 文件移植）：
- `_find_duplicate_headers` / `_reject_duplicate_headers`（MUSCLE 已有，MAFFT 也补上）
- `_detect_type` 字母验证逻辑
- MUSCLE 路径持久化：`_load_saved_muscle_path` / `_save_saved_muscle_path`（用现有 `user_data_file("config.ini")`）
- `_resolve_muscle_exe`
- 新增 `_build_muscle_command(muscle_exe, method, threads, input_path)`

**新增 _MuscleWorker(BaseWorker)**（替换原 QThread 版）：
- 继承 `BaseWorker`，用 `start_worker` 线程管理（修复原版无 stop + 遮蔽 finished 信号问题）
- `run()` 用 `subprocess.Popen` + `communicate(timeout=600)` + `kill_process_tree`（替换原 `subprocess.run`，使可取消）
- `stop()` 用 `kill_process_tree(self._proc)`

**新增 _MuscleBatchWorker**（从 MUSCLE 文件移植，`stop()` 改用 `kill_process_tree`）

**MafftAlignmentTab 改造**：
- 类名保持 `MafftAlignmentTab`（菜单标签改为 "Multiple Sequence Alignment"）
- `__init__`：加 `self._saved_muscle_path = self._load_saved_muscle_path()`
- `_setup_parameters`：Row 0 最左加 `engine_combo`；strategy_combo 选项由 `_on_engine_changed` 重填；order_combo 文案随之切换；exe 路径编辑框默认值随引擎切换
- `_setup_mode_tabs`：批量区加 `batch_engine_combo`；naming pattern 默认改为 `{stem}_msa_{method}`
- `run()`（单文件）：根据 engine 选 worker（`_MafftWorker` 或 `_MuscleWorker`）；MUSCLE 路径走持久化
- `_run_batch()`：根据 engine 选 `_MafftBatchWorker` 或 `_MuscleBatchWorker`
- 两个引擎共用输入校验：≥2 序列 + `_reject_duplicate_headers`；MUSCLE 额外跑 `_detect_type`
- `show_help`：合并两份帮助文档为一份
- CLUSTAL 输出表头根据引擎写 "(MAFFT alignment)" 或 "(MUSCLE v5 alignment)"

## 实施顺序
1. 在 mafft_alignment_tab.py 中移植 MUSCLE 助手与 worker（先不改 UI）
2. 加 engine_combo + `_on_engine_changed` 切换逻辑
3. 改 run() / _run_batch() 分派到对应 worker
4. 合并 help 文本
5. 删 multiple_sequence_alignment_tab.py + 清理 main_window/menus 接线
6. 迁移测试
7. 全量 `py -m pytest -q` + `ruff check` 验证零回归

## 风险与对策
- **既有 MAFFT 测试不破坏**：engine_combo 默认设为 MAFFT（index 0），所有现有 MAFFT 测试无需改 engine 即可通过
- **MUSCLE 路径持久化**：保留 config.ini `[MSA] muscle_exe` 机制，与 MAFFT 路径编辑框共存（引擎切换时切换显示的路径）
- **书签不受影响**：favorites_manager 是 URL 书签，不引用标签页类
