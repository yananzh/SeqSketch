# 数据一致性类修复计划（6 项修复 + 1 项 UI 移除）

## 修复 1：partition_concat 重复 ID 静默折叠
**文件**：`modules/partition_concat_tab.py:243-249`（`_concatenate_alignments`）

在 `_read_fasta` 之后、长度检查之前插入重复 ID 检测：用 `ids.count()` 找出重复的 taxon ID，发现即 `raise ValueError`（消息含文件名 + 前 5 个重复 ID 预览 + 引导用户用 Simplify Headers 去重）。这样 Run 路径与 Validate 按钮行为一致，异常由现有 worker 错误处理链弹出。

## 修复 2：MUSCLE 重复表头静默折叠
**文件**：`modules/multiple_sequence_alignment_tab.py:1134-1152`（`_parse_fasta`）、`:130-147`（`_parse_fasta_to_dict`）

`_parse_fasta`（单文件模式）解析完成后检查重复 header：若 `len(seqs) < 记录数`（字典折叠导致），抛 `ValueError` 列出重复的表头，提示先用 Deduplicate 工具去重。worker 的 except 链会以错误弹窗呈现，用户不会丢数据也不会得到条数不足的比对。`_parse_fasta_to_dict`（批量模式，约 :361 处调用）同样处理。注意去重统计需在字典折叠前做（计数原始 header 出现次数）。

## 修复 3：Filter by IDs 输出重复记录
**文件**：`modules/extract_by_id_tab.py:95-104`（Contains + Preserve Query Order 分支）

循环外加 `seen_headers = set()`；内层命中时按 `id(record)`（对象身份）判断，已输出的 record 跳过 append（`matched_query_flags[i] = True` 仍需执行，保证 missing_ids 计算正确）。这与 "Preserve FASTA Order" 分支的每记录一次语义一致。

## 修复 4：One Step resume 指纹校验
**文件**：`modules/one_step_multigenephy_workflow.py`

- 新增 `_project_fingerprint(project, cells, strain_order) -> str`：对 Excel 路径 + mtime + 选中基因列 + 菌株列表 + MAFFT/trimAl 模式 + bootstrap 参数做 SHA-256。
- Runner.run() 在 resume_mode ≠ "scratch" 时：读取上次 `06_reports/run_manifest.json` 中新增的 `input_fingerprint` 字段；不匹配或字段缺失则输出 WARNING 日志（“Workbook or parameters changed since last run — falling back to from-scratch”），并把 resume_mode 当作 "scratch" 继续全流程。
- 写 manifest 处（`write_run_manifest` 调用点）加入当前指纹。旧 manifest 无指纹字段 → 视为不匹配 → 自动降级，行为安全。

## 修复 5：BLAST 非 TSV 格式被强加表头
**文件**：`modules/blast_run_dialog.py:113-118`

写输出文件时仅当 `self.outfmt.startswith("6")` 才写 `_TSV_HEADER`，Pairwise(0)/XML(5) 输出原样。一处改动，`blast_local_tab` 传入的 outfmt 字符串以 "6"/"0"/"5" 开头，判断可靠。

## 修复 6：距离矩阵对角线改为 0
**文件**：`modules/distance_tree_tab.py:691-695`（显示）、`:727-748`（导出）

- 显示：`val = 1.0 if i == j else matrix[i][j]` → 直接用 `matrix[i][j]`（对角线本来就是 0），配色逻辑不变（本就只作用于非对角）。
- CSV/xlsx 导出：删除两处 `1.0 if i == j else v` / `"1.000000" if i == j` 的替换，导出真实 0 对角线；同时更新那条 "Replace diagonal 0→1 to match table display" 的过时注释。

## 修复 7：移除 "Preserve intermediate files" 复选框
