# 在 Windows 为项目创建虚拟环境并安装依赖

## 环境要求
- 已安装 `Python 3.11–3.13`（项目缓存显示 3.13 亦可）。
- 在 `PowerShell` 中操作，工作目录为 `d:\ui`。

## 创建并激活虚拟环境
- 进入项目目录：`cd d:\ui`
- 创建虚拟环境：`py -3 -m venv .venv`
- 激活虚拟环境：` .\.venv\Scripts\Activate.ps1`
- 升级工具链：`python -m pip install --upgrade pip setuptools wheel`

## 安装项目依赖
- 使用项目自带的依赖文件：`requirements.txt`
- 安装：`pip install -r requirements.txt`
- 若在国内网络环境，可使用镜像加速（可选）：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

## 验证安装
- 依赖导入自检：
  - `python -c "import PyQt6, numpy, matplotlib, Bio, scipy, primer3; print('ok')"`
- 运行程序验证：
  - `python main.py`

## 备用方案（Conda 用户）
- 创建环境：`conda create -n ui python=3.13 -y`
- 激活：`conda activate ui`
- 安装依赖：`pip install -r requirements.txt`

## 常见问题与建议
- 若遇到构建错误，先确保已执行工具链升级：`python -m pip install --upgrade pip setuptools wheel`。
- 若 `PyQt6` 的安装失败，通常是网络问题或旧版 `pip`，优先重试或切换镜像。
